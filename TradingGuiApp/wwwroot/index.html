About this project

Distributed message-driven trading system

A simple stock exchange built on RabbitMQ middleware. SendOrderApp publishes orders to the orders fanout exchange; ExchangeApp matches buy and sell orders against an in-memory order book and publishes completed trades to the trades exchange; this dashboard subscribes to both via SignalR for live per-stock updates without page refresh. Multiple stocks trade in parallel through isolated order books.

C# / .NET 10 RabbitMQ Fanout SignalR Multi-stock Docker A2 FR-01 / FR-05
