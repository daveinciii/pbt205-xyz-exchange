# pbt205-xyz-exchange

A CLI-based trading system built with .NET and RabbitMQ for PBT205.

## Prerequisites

- [.NET 10 SDK](https://dotnet.microsoft.com/download)
- [Docker Desktop](https://www.docker.com/products/docker-desktop)

## Getting Started

**1. Start RabbitMQ**
```bash
docker compose up -d rabbitmq
```

**2. Run the exchange**
```bash
dotnet run --project ExchangeApp -- <endpoint>
```

Example:
```bash
dotnet run --project ExchangeApp -- localhost
```

**3. Submit orders**

Open another terminal:

```bash
dotnet run --project SendOrderApp -- <username> <endpoint> <BUY|SELL> <quantity> <price>
```

Example — open two terminals:

```bash
dotnet run --project SendOrderApp -- Alice localhost BUY 100 10.50
dotnet run --project SendOrderApp -- Bob localhost SELL 100 10.20
```

If the buyer price is greater than or equal to the seller price, the exchange will execute a trade.

Example output:
```
Received order: Alice BUY 100 XYZ @ 10.50
No matching opposite-side order found.
Order added to the order book.

Received order: Bob SELL 100 XYZ @ 10.20
Trade executed:
Stock: XYZ
Buyer: Alice
Seller: Bob
Quantity: 100
Trade Price: 10.50
```

## Arguments

### SendOrderApp

| Argument | Description | Example |
|---|---|---|
| username | Trader identifier | Alice |
| endpoint | RabbitMQ host | localhost |
| side | Order type (BUY or SELL) | BUY |
| quantity | Number of shares (fixed at 100) | 100 |
| price | Desired price per share | 10.50 |

### ExchangeApp

| Argument | Description | Example |
|---|---|---|
| endpoint | Middleware endpoint | localhost |

## Order Schema
```csharp
public class Order
{
    public string Username { get; set; }
    public string Stock { get; set; }
    public OrderSide Side { get; set; }
    public int Quantity { get; set; }
    public double Price { get; set; }
    public DateTime CreatedAt { get; set; }
}
```

## Trade Schema
```csharp
public class Trade
{
    public string Stock { get; set; }
    public string Buyer { get; set; }
    public string Seller { get; set; }
    public int Quantity { get; set; }
    public double Price { get; set; }
    public DateTime ExecutedAt { get; set; }
}
```

## Topics

| Topic | Description |
|---|---|
| `orders` | Receives trader orders submitted by SendOrderApp |
| `trades` | Publishes completed trades generated by the exchange |

## Docker Services

| Service | Port | Description |
|---|---|---|
| RabbitMQ | 5672 | AMQP |
| RabbitMQ Management | 15672 | Dashboard (guest/guest) |
